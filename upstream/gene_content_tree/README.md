# Gene-content species-tree inference

This optional module constructs candidate species trees from curated proteomes using orthogroup presence–absence data.

It starts from protein sets and is independent of the annotation-curation implementation. Users may therefore use proteomes generated by [`../annotation_curation/`](../annotation_curation/) or supply independently curated proteomes.

## Dependencies

- Bash 4+
- Python 3.10+
- [OrthoFinder](https://orthofinder.github.io/OrthoFinder/)
- [IQ-TREE](https://iqtree.github.io/)

## Input organization

Arrange one or more protein datasets as subdirectories. Each dataset must contain at least three species-level `.faa` files:

```text
protein_sets/
├── all/
│   ├── SpeciesA.faa
│   ├── SpeciesB.faa
│   └── SpeciesC.faa
└── min100aa/
    ├── SpeciesA.faa
    ├── SpeciesB.faa
    └── SpeciesC.faa
```

## 1. Infer orthogroups with OrthoFinder

```bash
./01_run_orthofinder.sh \
  --sets-dir protein_sets \
  --out-dir work/01_orthofinder \
  --threads 16
```

Each protein dataset is analyzed independently. The script writes a manifest linking each dataset to its `Orthogroups.GeneCount.tsv` file:

```text
work/01_orthofinder/gene_count_tables.tsv
```

## 2. Build binary gene-content matrices

```bash
./02_build_matrices.sh \
  --gene-count-manifest work/01_orthofinder/gene_count_tables.tsv \
  --out-dir work/02_matrices
```

For each OrthoFinder run, the module produces an `all_families` matrix containing orthogroups present in at least one but not all species.

Multi-copy families are collapsed to binary presence. Universal families are excluded because they contain no presence–absence variation.

The matrix utility can also be called directly:

```bash
python3 scripts/build_gene_content_matrix.py \
  --gene-count example/Orthogroups.GeneCount.tsv \
  --out-prefix example/example_matrix
```

Outputs include a human-readable TSV matrix, a PHYLIP binary matrix for IQ-TREE, and a summary file.

## 3. Infer species trees with IQ-TREE

```bash
./03_infer_species_trees.sh \
  --matrix-dir work/02_matrices \
  --out-dir work/03_trees \
  --outgroup SpeciesOutgroup \
  --threads 16 \
  --bootstraps 1000
```

The default model is:

```text
MK+R+FO+ASC
```

The wrapper uses standard nonparametric bootstrapping (`-b 1000`). If `--outgroup` is omitted, IQ-TREE's default rooting behavior is retained.

The resulting `*.treefile` files are candidate fixed species-tree hypotheses that can be screened in the core D-BPP workflow. Gene-content is one optional route to a species tree; sequence-based or literature-supported alternatives can be evaluated in parallel.

## Minimal matrix example

The [`example`](example/) directory contains a small synthetic OrthoFinder-style gene-count table. It exercises matrix conversion without requiring OrthoFinder:

```bash
python3 scripts/build_gene_content_matrix.py \
  --gene-count example/Orthogroups.GeneCount.tsv \
  --out-prefix example/example_matrix
```

## Interpretation

Gene-content trees are sensitive to annotation completeness and systematic differences among annotations. Treat this module as a reproducible candidate species-tree construction route rather than evidence that a gene-content topology is necessarily the true species tree. Compare plausible alternative species trees in downstream D-BPP analyses when annotation quality, taxon sampling, or genomic history creates uncertainty.

Manuscript-specific perturbation and robustness analyses are not included in this public workflow.
